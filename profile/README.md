## What we build

DurraFX builds **DurraPay**, a payments platform that lets businesses collect, hold, convert and send money across borders.

- **Collect** from customers by mobile money and bank, with payment links and a hosted checkout.
- **Pay out** to mobile wallets and bank accounts, one at a time or in bulk.
- **Hold and convert** balances in multiple currencies, with quoted FX rates.
- **Settle automatically** to a saved destination on a daily, weekly or monthly schedule.

## For developers

DurraPay has a REST API for everything the dashboard does.

- OAuth2 client credentials, with scoped access per client
- Idempotency keys on every write, so a retry never pays twice
- Signed webhooks for payment, payout and settlement events
- Collections, transfers, bulk transfers, payment links, balances and transactions

Create API credentials under **Developers → API Keys** in the [dashboard](https://dashboard.durrapay.com), then follow the [API docs](<TODO: API docs URL>).

## How we handle money

- Every movement is recorded in a double-entry ledger.
- Businesses and their directors are verified before they can move money.
- Transactions are screened and monitored for fraud and money laundering.
- Sensitive actions need a second verification step.
